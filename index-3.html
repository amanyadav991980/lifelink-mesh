Emergency communication concept

LifeLink Mesh

When mobile networks fail, phones can still pass an SOS from one to the next until it reaches rescue teams. Try it below.

You Relay phones Rescue base Offline
Tap any coloured phone to switch it off, then send the SOS and see if it still finds a route.

How it works

Connect

Each phone links to nearby phones using Bluetooth or Wi-Fi Direct.

Hop

The SOS message jumps from phone to phone until it reaches a rescue base.

Reroute

If one phone goes offline, the message looks for another path.
